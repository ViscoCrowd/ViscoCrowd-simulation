# Planning ViscoCrowd 2026–2027

[Ouvrir le planning détaillé au format Excel](planning-viscocrowd-2026-2027.xlsx).

Le classeur fourni par le groupe est versionné ici pour centraliser le suivi du projet.
Cette première copie conserve son contenu et sa mise en forme à l'identique.

Pour une mise à jour, modifier ce fichier puis proposer les changements sur une branche de
documentation. Les fichiers temporaires Excel dont le nom commence par `~$` ne doivent pas être
ajoutés aux commits.

L'état des jalons est présenté dans le [README du projet](../../README.md#état-davancement).
